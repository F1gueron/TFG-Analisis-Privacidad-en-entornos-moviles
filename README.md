# TFG - Análisis de Privacidad en Entornos Móviles

Trabajo de Fin de Grado centrado en el análisis de privacidad en aplicaciones móviles.

## Contenido del repositorio

- `frida-server` — servidor de Frida para instrumentación dinámica.
- `root-sslpining.js` — script de Frida para bypass de SSL pinning.
- `cacert.crt` / `cacert.der` — certificados utilizados en el análisis.
- `requirements.txt` — dependencias de Python.
